Centinela 1.4

🇪🇸👑

➕Añadido

▶️Herramienta Geozonas: crea alertas a partir de zonas dibujadas, activa avisos de entrada y salida, filtra objetivos entre usuarios TAK, enemigos o ambos y consulta el historial de cruces.
▶️Alertas de geozona: recibe notificaciones locales con banner, sonido o vibración y contador cuando un objetivo cruza una geozona. La ocupación de cada zona se almacena para evitar alertas duplicadas.

🔄Mejorado

▶️Mapas y KMZ: detección de GroundOverlay en archivos KML/KMZ, incluidos los paquetes de datos, para importar correctamente mapas georreferenciados.
▶️Mapa táctico: seguimiento de la región visible para georreferenciar utilizando el encuadre actual y evaluar las geozonas con los datos mostrados en el mapa.

🇺🇸👑

➕Added

▶️Geofence tool: create alerts from drawn areas, enable entry and exit notifications, filter targets between TAK users, enemies, or both, and review the crossing history.
▶️Geofence alerts: receive local notifications with banners, sound or vibration, and a badge counter whenever a target crosses a geofence. Zone occupancy is tracked to prevent duplicate alerts.

🔄Improved

▶️Maps and KMZ: added GroundOverlay detection in KML/KMZ files, including data packages, for correct import of georeferenced maps.
▶️Tactical map: tracks the visible map region to georeference using the current view and evaluate geofences with the displayed map data.
